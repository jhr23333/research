## 信号规则

> 只有**负向/异常**信号写入假设.md，正向趋势仅在看板里记录，不追加待核实问题。
> ⚠️ 以下规则中的 H# 在北方华创覆盖建立后由 /alt-data 首次运行时校准。

| 数据源 | 触发条件（负向） | 动作 |
|--------|--------------|------|
| 韩国半导体出口前10日同比 | 连续2月同比 < -10% | 追加至北方华创 假设.md（存储扩产收缩风险） |
| SIA全球销售额同比 | 单月同比转负，或连续2月跌幅扩大 >5pp | 追加至北方华创 假设.md（行业景气拐点风险） |
| 日本设备出货额 | 连续3月环比下滑 | 追加至北方华创 假设.md（全球设备需求收缩信号） |
| 国内晶圆厂资本开支公告 | 中芯/华虹/晶合任一下修资本开支指引 | 追加至北方华创 假设.md（核心客户订单风险） |
| 国内晶圆厂招标公告 | 出现刻蚀/沉积设备外资中标集中化 | 记录在看板摘要，由研究员手动判断是否追加（份额信号，不自动写入） |

## 说明

- 数据层：`data\` 只存原始 CSV，不做分析
- 信号层：脚本运行后自动判断是否触发阈值，触发则写入公司 `假设.md`
- 看板层：`看板\` 笔记负责可视化，通过 `![[]]` 嵌入图表
- 所有数据系列在登记表里必须填写"关联假设"，孤立数据不入库
